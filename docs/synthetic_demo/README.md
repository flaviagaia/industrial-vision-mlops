# Evidências da demonstração sintética

Execução de oito épocas em CPU sobre 40 imagens geométricas artificiais.
Estas imagens não são aço real, e as métricas não representam o dataset Severstal.
Os exemplos visuais são erros reais deste modelo na demonstração.

O checkpoint e o dataset gerado permanecem em artifacts/synthetic_portfolio na máquina local.
Código, testes e notebook são distribuídos sem dados da competição ou checkpoints.

Validação: 18 testes automatizados passaram; Ruff sem erros. Notebook independente
validado em modo sintético, com as 15 células de código executadas (uma época).
A execução Kaggle com GPU e o treino no Severstal não foram realizados.
